STEP 01

1. 컴퓨터는 왜 여러 모양의 커서를 쓸까요?

마우스 커서는 단순한 화살표가 아니에요. 현재 내가 어떤 행동을 할 수 있는지 알려주는 컴퓨터의 '대화 수단'이랍니다!

🏹 기본 선택 (default)

평소 가장 많이 쓰는 화살표

📋 텍스트 선택 (text)

글자를 드래그하거나 쓸 때

🔃 이동 (move)

창이나 객체를 끌어서 옮길 때

❓ 도움말 (help)

물음표 설명이 필요할 때

STEP 02

2. 나만의 커서 이미지 만들기

마우스 커서로 쓸 그림이나 캐릭터 이미지를 준비해 볼까요?

1

커서로 만들고 싶은 이미지 다운로드하기

나만의 커서로 만들고 싶은 이미지를 구글에 검색합니다. 원하는 이미지를 클릭 후 마우스 오른쪽 버튼을 클릭하고 '이미지를 다른 이름으로 저장'을 클릭하여 저장합니다.

2

🤖 생성형 AI로 커서용 이미지 준비하기

제미나이(또는 다른 생성형 AI)에 다운로드받은 이미지를 첨부한 뒤, 아래와 같은 내용으로 프롬프트를 작성하여 이미지를 생성해 보세요.

💬 AI 프롬프트 작성 팁:

"이 이미지를 마우스 커서용으로 다시 만들어줘."

  • 1) 1:1 비율로 정사각형
  • 2) 클릭 지점을 구체적으로 설정 ex. 왼쪽 귀가 좌측 상단을 향하게(클릭 지점)
  • 3) 32X32 픽셀에서도 잘 보이게 단순화
  • 4) 두꺼운 외곽선 추가
  • 5) 배경은 단색 또는 단순하게
예시: 1:1 정사각형 이미지
STEP 03

3. 나만의 커서 이미지를 .cur 파일로 변환하기

윈도우 마우스 커서로 쓰려면 일반 PNG 그림을 윈도우 전용 커서 확장자인 .cur 형식으로 바꿔주어야 합니다.

온라인 커서 변환기 활용

준비한 PNG 이미지를 .cur 커서 파일로 즉시 무료 변환할 수 있습니다.

STEP 04

4. 핫스팟(클릭 지점) 탐색하기

준비한 이미지를 올려보세요! 어디를 눌러야 진짜 클릭이 일어나는지 직접 체험해 볼 수 있어요.

왼쪽 이미지 위에서 진짜 클릭 신호가 들어갈 위치(예: 캐릭터의 코, 화살표의 뾰족한 끝 등)를 마우스로 직접 콕 눌러보세요!

지정된 좌표: X: 0, Y: 0

빨간 점이 찍힌 자리가 마우스로 클릭할 때 실제로 명령이 들어가는 단 1픽셀 지점입니다.

💡 오른쪽 격자판에 마우스를 대면 설정한 핫스팟이 적용된 커서가 나타나요!

클릭 지점!
이미지를 올린 후
이 위로 마우스를 올려보세요!

💡 전문가의 팁: 핫스팟(Hotspot)이란?

이미지 파일은 크기가 커도, 실제로 컴퓨터가 "클릭했다"고 판단하는 영역은 단 1픽셀이에요!
이 지점을 핫스팟이라고 하며, 위치 설정을 잘못하면 조준이 안 맞아 불편한 마우스가 된답니다.

STEP 05

5. 다운로드 한 커서 파일을 전용 폴더로 이동하기 & 적용하기

📌 [가장 중요한 핵심 팁!]

다운로드한 커서 파일(.cur)은 반드시 C:\Windows\Cursors 폴더로 이동해서 넣고 사용하는 걸 권장합니다.

바탕화면이나 다운로드 폴더에 그대로 둔 채 설정하면, 나중에 폴더를 정리하거나 실수로 파일이 삭제되었을 때 컴퓨터 재부팅 후 커서가 윈도우 기본 화살표로 되돌아가버리기 때문이에요!

A

안전하게 파일 옮기기

  1. 다운로드한 .cur 커서 파일을 복사(Ctrl+C)합니다.
  2. [내 PC] → [로컬 디스크 (C:)] → [Windows] → [Cursors] 폴더로 이동합니다.
  3. 폴더 안에 복사한 커서 파일을 붙여넣기(Ctrl+V)합니다. (관리자 권한 메시지가 나오면 '계속' 클릭)
B

윈도우 포인터 설정에서 적용하기

  1. 윈도우 시작 메뉴에서 [설정] → [장치] → [마우스]로 이동합니다.
  2. 우측 상단의 [추가 마우스 옵션]을 눌러 마우스 속성 창을 엽니다.
  3. [포인터] 탭 ➔ 목록의 '일반 선택'을 더블클릭 ➔ 아까 옮겨둔 `C:\Windows\Cursors` 안의 `.cur` 파일 선택 ➔ [적용] 및 [확인] 클릭!
